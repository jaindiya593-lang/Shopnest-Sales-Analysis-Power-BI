ShopNest Store Sales Analysis — Power BI

## Project Overview
This project uses Microsoft Power BI to explore e-commerce sales data and present key metrics through an interactive dashboard.

## Dashboard Preview
The dashboard preview will be added here after uploading a screenshot of the completed report.

## Business Questions
- How does revenue vary across product categories and states?
- What sales trends can be observed over time?
- What do customer ratings tell us about the products?
- What does the data show about delivery performance?

## Tools Used
- Microsoft Power BI
- Data visualization
- KPI reporting
- Data analysis

## Key Performance Indicators
The dashboard explores revenue, order volume, customer ratings, and delivery performance. Exact KPI definitions and DAX measures will be documented after verifying them in the report.

## Key Findings
Findings will be added after checking the completed dashboard to ensure that all reported values are accurate.

## How to Open the Project
1. Download `Shop Nest Dashboard.pbit` from this repository.
2. Open the template in Power BI Desktop.
3. Follow the prompts to provide the required data-source details or input files.
4. Refresh the data and verify that the dashboard visuals load correctly.
