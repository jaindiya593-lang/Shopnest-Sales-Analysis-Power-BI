## Dataset and Data Sources

This project uses e-commerce dataset files provided through Skillovilla course materials for a Power BI sales analysis exercise.

The data covers business areas including orders, customers, products, payments, sellers, reviews, and delivery performance.

## Obtaining the Data

The original input files are available through the Skillovilla course materials. Authorized reviewers can obtain them through the course resources, subject to the provider's access and usage terms.

The dataset is not linked as a public download because its public availability and redistribution permissions have not been verified.

## How to Open the Project

### Requirements
- Microsoft Power BI Desktop
- The `Shop Nest Dashboard.pbit` template from this repository
- The original dataset files available through Skillovilla course materials

### Setup Instructions
1. Obtain the permitted dataset files through the Skillovilla course materials.
2. Download `Shop Nest Dashboard.pbit` from this repository.
3. Open the template in Power BI Desktop.
4. If prompted, provide the required data-source parameters.
5. If the template cannot locate the original files, open Power Query Editor and update the source paths to point to the correct local files.
6. Apply the changes and refresh the data.
7. Verify that the visuals, relationships, and measures load correctly.

**Note:** The exact reconnection steps depend on the original template configuration. Do not upload private credentials or restricted dataset files to GitHub.
